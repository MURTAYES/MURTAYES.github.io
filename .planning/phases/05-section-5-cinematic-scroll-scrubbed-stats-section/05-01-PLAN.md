- Pinned between Section 4 (`#works`) and Section 6 (`#building`).
- Zero external libraries: pure CSS and 60fps vanilla JavaScript inside `requestAnimationFrame`.

  2. `18+` — Digital Projects & Systems Shipped
  3. `100%` — Core Web Vitals & Lighthouse Performance Score

<task type="auto">
  <name>Task 3: 60fps Scroll-Scrubbed Controller & Number Roll-up Engine</name>
  <files>js/stats.js</files>
  <action>
    Create `js/stats.js`:
    1. Scroll progress computation:
       - `rect = track.getBoundingClientRect()`.
       - `progress = Math.max(0, Math.min(1, -rect.top / (rect.height - window.innerHeight)))`.
    2. Interpolation phases:
       - Phase 1 (0.00 -> 0.42):
         - `insetY = 18 * (1 - p1) %`, `insetX = 20 * (1 - p1) %`.
         - `scale = 1.16 - (0.16 * p1)`.
         - Apply `clipPath = inset(${insetY}% ${insetX}%)` and `transform = scale(${scale})`.
       - Phase 2 (0.28 -> 0.58):
         - Scrim opacity: `0 -> 0.58`.
       - Phase 3 (0.34 -> 0.60):
         - Content opacity: `0 -> 1`, `translateY: 40px -> 0px`.
       - Phase 4 (0.40 -> 0.70):
         - Hairlines `scaleX: 0 -> 1` with staggered indices.
       - Phase 5 (0.45 -> 0.85):
         - Number counter interpolation: smoothly roll numbers from 0 up to `data-target` using eased progress `easeOutExpo(pNum)`.
    3. Performance:
       - Driven via `requestAnimationFrame` on scroll/resize.
       - Respect `prefers-reduced-motion`.
       - Zero layout thrashing: cache rect heights and elements.
  </action>
