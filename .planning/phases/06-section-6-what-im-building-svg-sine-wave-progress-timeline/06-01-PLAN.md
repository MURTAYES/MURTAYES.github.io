# Plan 06-01: What I'm Building: SVG Sine-Wave Progress Timeline

Build Section 6: "What I'm Building" (`#building`), a minimalist dark-theme interactive progress timeline visualizing active builds and milestones along an SVG sine wave with synchronized station pop-in nodes, alternating callout cards, link redraw hover effects, and a responsive Swiss-style mobile index.

1. **ApplyKit** (Station 1: Crest `x: 175, y: 35` — Above curve):
   - Status: `Production / Active`

   - Status: `Deployed / Scaling`
   - Description: Enterprise multi-tenant pharmaceutical inventory & distribution engine.
3. **EduHub / Edu52** (Station 3: Crest `x: 675, y: 35` — Above curve):
   - Status: `Active Build / 76% WIP`

   - Status: `Shipped / v1.0`
   - Description: 60fps zero-dependency interaction architecture & bespoke portfolio.
