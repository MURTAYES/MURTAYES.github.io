<task type="auto">
  <name>Task 3: Section 7 JavaScript Controller & Autonomous Cursor</name>
  <files>js/contact.js</files>
  <action>
    Create `js/contact.js`:
    1. Scope in IIFE with `"use strict";`.
    2. Stage element `.js-contacto-stage` and cursor `.js-cliente-cursor`.
    3. Autonomous Lissajous path motion:
       - In `requestAnimationFrame` loop, calculate `x = stageWidth * (0.5 + 0.35 * Math.sin(t * 0.0012 + 0.5))` and `y = stageHeight * (0.5 + 0.32 * Math.sin(t * 0.0009 * 1.5))`.
       - Set `cursor.style.transform = translate3d(${x}px, ${y}px, 0)`.
       - Update stage custom properties: `--dot-lit-x: ${x}px; --dot-lit-y: ${y}px;`.
    4. Mouse interaction:
       - On `mouseenter` or `mousemove` over `.js-contacto-stage`: smoothly interpolate cursor position towards user mouse `(e.clientX - rect.left, e.clientY - rect.top)`.
       - On `mouseleave`: smoothly return to autonomous Lissajous curve.
    5. Parallax float on floating cards:
       - Subtle damping offset on `mousemove` for cards with `data-float="true"`.
    6. Respect `prefers-reduced-motion`:
       - If reduced motion requested, park cursor at `(65%, 45%)` and disable continuous animation loop.
    7. Expose `window.initContactSection` and auto-initialize on DOMContentLoaded.
  </action>
