# Plan 08-01: Section 8 — Minimalist Single-Line Colophon Footer

## Objective

Replace the legacy oversized kinetic footer with Section 8: "Minimalist Single-Line Colophon Footer" (`.site-colophon`), delivering an understated architectural baseline directly beneath the collaborative workspace contact section with dynamic copyright year, live Dhaka timezone clock, and clean links.

## Requirements Covered

- **FOOT-01**: Full-width container with subtle 1px dashed architectural blueprint divider sitting cleanly below `home-contacto`.
- **FOOT-02**: Single-line typographic editorial colophon in `'Plus Jakarta Sans'` (`0.875rem`).
- **FOOT-03**: Dynamic current year updated automatically via JavaScript (`#footer-year`).
- **FOOT-04**: Clean address/location, service/social links, and back-to-top button with subtle hover transitions.
