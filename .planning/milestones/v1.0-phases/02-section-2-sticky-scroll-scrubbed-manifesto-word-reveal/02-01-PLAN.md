# Plan 02-01: Sticky Scroll-Scrubbed Manifesto Word Reveal

## Objective

Replace the legacy `#about` section with the production-grade sticky scroll-scrubbed manifesto word reveal section (`.home-quote-block`) featuring a `260vh` scroll track, pinned `100vh` viewport, radial dot matrix parallax background, two-tier word tokenization, and sequential scroll-driven word revealing physics.

## Context & User Decisions

- Replaces the old `about-section` in `index.html` with `<section id="about" class="home-quote-block wp-block-onlines-home-quote-block is-animating">`.
- Outer track height is `260vh` with `position: relative; background: #ffffff;`.
- Inner sticky viewport is `position: sticky; top: 0; height: 100vh; display: flex; align-items: center; justify-content: center; overflow: hidden;`.
- Background dot grid (`.patron-puntos.js-quote-dots`) uses radial gradient with circular mask and vertical parallax shift.
- Two groups:
  - Primary heading (`data-quote-group="titulo"`): "Hacemos sitios web de alta calidad para empresas, gobiernos y organizaciones."
  - Secondary subtitle (`data-quote-group="subtitulo"`): "Siguiendo nuestro objetivo de que internet sea un lugar mejor."
- Each word wrapped in `<span class="js-quote-word">`.

<task type="auto">
  <name>Task 3: Scroll-Scrubbed Word Reveal & Parallax Engine</name>
  <files>js/quote.js</files>
  <action>
    Create `js/quote.js` implementing the scroll-scrubbing engine:
    1. Select `.home-quote-block`, `.js-quote-dots`, title words (`[data-quote-group="titulo"] .js-quote-word`), and subtitle words (`[data-quote-group="subtitulo"] .js-quote-word`).
    2. Define helper `clamp(val, min, max)` and `animateWordGroup(words, groupProgress)`:
       - Calculate individual word threshold `start = index / total` and `end = start + (1 / total)`.
       - Compute `wordProgress = clamp((groupProgress - start) / (end - start), 0, 1)`.
       - Interpolate `opacity = 0.12 + wordProgress * 0.88`, `translateY = (1 - wordProgress) * 10px`, `blur = (1 - wordProgress) * 2px`.
    3. Define `updateQuoteOnScroll()`:
       - Measure `rect = quoteSection.getBoundingClientRect()`.
       - Calculate normalized progress `rawProgress = -rect.top / (rect.height - window.innerHeight)`.
       - Map progress `0.05 -> 0.60` to animate title words.
       - Map progress `0.62 -> 0.95` to animate subtitle words.
       - Shift `.js-quote-dots` vertically by `(progress - 0.5) * -45px`.
    4. Attach passive scroll and resize listeners using `requestAnimationFrame`. Execute on DOMContentLoaded and initial load.
  </action>
