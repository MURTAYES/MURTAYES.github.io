# Samnun Murtayes — Personal Portfolio

## What This Is

A bespoke, high-performance personal portfolio website for creative engineer and developer Samnun Murtayes. Built strictly with semantic HTML5, modern CSS, and vanilla JavaScript, it blends kinetic preloader animations, collaborative design canvas metaphors, tactile architectural folder archives, and precision scroll-scrubbed narrative transitions.

## Core Value

Demonstrate world-class frontend engineering, creative design systems, and tactile digital craftsmanship through pure vanilla web technologies (HTML, CSS, JavaScript) with zero runtime dependencies.

## Business Context

- **Audience**: Engineering leaders, creative directors, high-growth startups, and clients seeking bespoke digital experiences and creative engineering.
- **Goal**: Convert visitors into high-value project inquiries, technical advisory engagements, and engineering collaborations.
- **Success metric**: Engagement depth (scroll completion through manifesto, stats, and works) and contact CTA conversions.

### Out of Scope

- **Frontend frameworks (React, Next.js, Vue)**: Explicitly prohibited; must use vanilla HTML, CSS, and JS.
- **Unmentioned legacy features**: Old `#process` integrations section, Matter.js `#global-physics-stage`, and old `#about` section are purged.
- **Heavy external animation libraries**: Keep runtime lean using native Web APIs (`requestAnimationFrame`, `IntersectionObserver`, CSS custom properties, and SVG).

## Constraints

- **Tech Stack**: HTML5, CSS3 (CSS Variables, Flexbox, Grid, Clamp), Vanilla JavaScript (ES6+).
- **Zero Heavy Dependencies**: No heavy bundles or bundler requirements. Fast, direct in-browser execution.
- **Responsiveness**: Flawless experience from 360px mobile screens up to ultrawide 4K displays.
- **Performance**: High frame rate (60fps) animations utilizing hardware-accelerated transforms (`translate3d`, `opacity`, `scale`).
